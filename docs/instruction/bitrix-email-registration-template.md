# Шаблон письма для админки Битрикса: код подтверждения регистрации

Этот шаблон соответствует текущей реализации отправки через почтовое событие Битрикса.

## Рекомендуемый код почтового события

```text
REBIT_AUTH_REGISTRATION_CONFIRMATION
```

## Рекомендуемые макросы

```text
#EMAIL_TO#
#CONFIRMATION_CODE#
#EXPIRES_AT#
```

## Тема письма

```text
Rebit P2P — код подтверждения регистрации
```

## HTML-версия письма

```html
<p>Здравствуйте!</p>

<p>
    Вы запросили регистрацию в <strong>Rebit P2P</strong>.
</p>

<p>
    Ваш код подтверждения:
</p>

<p style="font-size: 24px; font-weight: bold; letter-spacing: 4px; margin: 16px 0;">
    #CONFIRMATION_CODE#
</p>

<p>
    Код действует до <strong>#EXPIRES_AT#</strong>.
</p>

<p>
    Если вы не запрашивали регистрацию, просто проигнорируйте это письмо.
</p>

<hr>

<p style="color: #777; font-size: 12px;">
    Это автоматическое письмо, пожалуйста, не отвечайте на него.<br>
    Получатель: #EMAIL_TO#
</p>
```

## Text-версия письма

```text
Здравствуйте!

Вы запросили регистрацию в Rebit P2P.

Ваш код подтверждения: #CONFIRMATION_CODE#

Код действует до #EXPIRES_AT#.

Если вы не запрашивали регистрацию, просто проигнорируйте это письмо.

Это автоматическое письмо, пожалуйста, не отвечайте на него.
Получатель: #EMAIL_TO#
```

## Описание типа события

```text
#EMAIL_TO# - e-mail получателя
#CONFIRMATION_CODE# - 6-значный код подтверждения
#EXPIRES_AT# - дата и время окончания действия кода
```

## Что вставлять в админке Битрикса

### Тип почтового события

- **Символьный код:** `REBIT_AUTH_REGISTRATION_CONFIRMATION`
- **Описание:**

```text
#EMAIL_TO# - E-mail получателя
#CONFIRMATION_CODE# - Код подтверждения регистрации
#EXPIRES_AT# - Время окончания действия кода
```

### Почтовый шаблон

- **Кому:** `#EMAIL_TO#`
- **Тема:** `Rebit P2P — код подтверждения регистрации`
- **Тип письма:** HTML
- **Тело:** используйте HTML-шаблон выше
