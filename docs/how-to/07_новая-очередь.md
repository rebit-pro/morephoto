# Как добавить новую очередь

Короткая инструкция. Подробности и обоснования: [../architecture-guide/15_очереди-и-консьюмеры.md](../architecture-guide/15_очереди-и-консьюмеры.md).

## Что получится

```text
Отправка:  Любой код → Publisher → MessageBus → AMQP → RabbitMQ
Обработка: CLI Worker → AMQP ← RabbitMQ → MessageBus → Handler
```

## Шаги

### 1. Добавьте очередь в enum

```php
// rebit.share/lib/Shared/Enum/MessengerQueueEnum.php

case NOTIFICATION_EMAIL = 'notificationEmail';
```

### 2. Создайте сообщение

```php
// lib/Application/<Domain>/Message/<Name>Message.php

final readonly class EmailNotificationMessage extends AbstractMessage
{
    public function __construct(
        public int $userId,
        public string $templateCode,
    ) {
        parent::__construct();
    }
}
```

Кладите в сообщение только скаляры и ID. Handler сам достанет данные из БД.

Если нужна дедупликация — переопределите `getDeduplicationKey()`.

### 3. Создайте handler

```php
// lib/Application/<Domain>/Message/Handler/<Name>MessageHandler.php

final readonly class EmailNotificationMessageHandler
{
    public function __construct(
        private EmailSenderInterface $emailSender,
        private LoggerInterface $logger,
    ) {}

    public function __invoke(EmailNotificationMessage $message): void
    {
        $this->logger->info('Отправка email', ['user_id' => $message->userId]);
        $this->emailSender->send($message->userId, $message->templateCode);
    }
}
```

Handler не должен глотать исключения — иначе Messenger не выполнит retry.

### 4. Создайте фабрику маршрутов

```php
// lib/Infrastructure/<Domain>/Messenger/<Name>MessengerFactory.php

final class NotificationMessengerFactory extends AbstractMessengerFactory
{
    protected static function routes(): array
    {
        return [
            new MessengerRouteDto(
                messageClass: EmailNotificationMessage::class,
                handlerClass: EmailNotificationMessageHandler::class,
                queue: MessengerQueueEnum::NOTIFICATION_EMAIL,
            ),
        ];
    }
}
```

### 5. Зарегистрируйте транспорт в DI

```php
// di/Messenger.php

return [
    MessengerQueueEnum::NOTIFICATION_EMAIL->transportKey() => [
        'constructor' => static fn(): TransportInterface => ServiceLocator::getInstance()
            ->get(AmqpConnectionFactory::class)
            ->create(MessengerQueueEnum::NOTIFICATION_EMAIL),
    ],
];
```

### 6. Зарегистрируйте handler в DI

```php
// di/<Domain>.php

return [
    EmailNotificationMessageHandler::class => [
        'className' => EmailNotificationMessageHandler::class,
        'constructorParams' => static fn(): array => [
            ServiceLocator::getInstance()->get(EmailSenderInterface::class),
            Log::getLogger(LogChannelEnum::notification),
        ],
    ],
];
```

### 7. Используйте publisher для отправки

```php
final readonly class SendEmailNotificationUseCase
{
    public function __construct(
        private MessagePublisherInterface $publisher,
    ) {}

    public function execute(int $userId, string $templateCode): void
    {
        $this->publisher->dispatch(
            new EmailNotificationMessage(
                userId: $userId,
                templateCode: $templateCode,
            ),
        );
    }
}
```

Publisher получаем через фабрику в DI:

```php
SendEmailNotificationUseCase::class => [
    'className' => SendEmailNotificationUseCase::class,
    'constructorParams' => static fn(): array => [
        NotificationMessengerFactory::createPublisher(ServiceLocator::getInstance()),
    ],
],
```

### 8. Создайте CLI-команду для консьюмера

```php
// lib/Presentation/Command/<Domain>/<Name>ConsumerCommand.php

#[AsCommand(
    name: 'app:notification:email-consume',
    description: 'Консьюмер очереди email-уведомлений',
)]
final class EmailNotificationConsumerCommand extends Command
{
    // аналогично FacetUpdateConsumerCommand
}
```

## Где лежат файлы

| Что | Путь |
|-----|------|
| Enum очередей | `rebit.share/lib/Shared/Enum/MessengerQueueEnum.php` |
| Сообщение | `lib/Application/<Domain>/Message/<Name>Message.php` |
| Handler | `lib/Application/<Domain>/Message/Handler/<Name>MessageHandler.php` |
| Фабрика маршрутов | `lib/Infrastructure/<Domain>/Messenger/<Name>MessengerFactory.php` |
| DI транспортов | `di/Messenger.php` |
| CLI-команда | `lib/Presentation/Command/<Domain>/<Name>ConsumerCommand.php` |

## Чеклист

- [ ] Case добавлен в `MessengerQueueEnum`
- [ ] Сообщение наследует `AbstractMessage`
- [ ] В сообщении только скаляры и ID
- [ ] Handler принимает сообщение через `__invoke()`
- [ ] Handler не глотает исключения
- [ ] Фабрика наследует `AbstractMessengerFactory`
- [ ] Транспорт зарегистрирован в `di/Messenger.php`
- [ ] Handler зарегистрирован в DI
- [ ] Publisher создаётся через `YourFactory::createPublisher()`
- [ ] CLI-команда создана и подключена
