# Именование классов

Именование классов/методов/функций с помощью суффиксов и префиксов преследует собой их однозначную идентификацию по назначению без необходимости смотреть в код. Это очень сильно поднимает читаемость кода, особенно при code review.

Список ниже не полный. В общем случае, если вы смотрите на название класса и, чтобы понять что же он делает, вам нужно лезть в исходный код, то с названием что-то не так.

## Ключевые принципы

- **Суффикс** = тип объекта (Service, Repository, Exception)
- **Префикс** = область ответственности (UserCreate, OrderUpdate)
- **Без сокращений** (Notification, а не Notif)

## 1. Сущности/модели, Value Object, Фасады

Сущности/модели/Value Object не имеют префиксов и суффиксов.

```php
final class TimeSlot { }
```

## 2. Контроллеры

Контроллеры имеют суффикс `Controller`.

```php
final class FileController extends AbstractController { }
```

## 3. Сервисы

Сервисы имеют префикс сущности/домена, к которой они относятся, далее идет необязательное уточнение назначения сервиса и в конце суффикс `Service`. За исключением специализированных сервисов, которые имеют префиксы аналогично их назначению, например UrlResolver, UrlBuilder, UrlChecker и т.п.

```php
// сервис относится к сущности Some
final class SomeService { }

// сервис относится к сущности Pet, занимается ее созданием
final class PetCreateService { }
```

## 4. Исключения

Исключения имеют суффикс `Exception`.

```php
final class CoordinatesNotInCityException extends Exception { }
```

## 5. Репозитории

Репозитории имеют суффикс `Repository`.

```php
final class AddressRepository { }
```

## 6. DTO — объект для передачи данных между слоями и внутри домена

В общем случае имеют суффикс Dto.

```php
// объект передачи данных, передает данные
final class UserListItemDto { }
```

## 7. RequestDto — специально выделенный объект для получения данных в контроллере

RequestDto имеет префикс сущности или домена, для которого он используется, затем идет действие (создание/изменение/удаление/отображение), в конце суффикс `RequestDto`. Так же реализует интерфейс `RequestDtoInterface`.

```php
// объект передачи данных, который создает сущность User
final class UserCreateRequestDto implements RequestDtoInterface { }
```

## 8. ResultDto — обязательный объект для ответа из контроллеров, допустим в других контекстах

ResultDto имеет префикс сущности, либо отражает суть того, что отдается клиенту, и суффикс `ResultDto`. Суффикс `ResultDto` **обязателен** для DTO, возвращаемых из контроллеров. Также допускается использование `ResultDto` в других контекстах (межслойная передача, ответы UseCase и пр.).

```php
// объект передачи данных, который возвращает сущность адрес пользователя
final class UserAddressResultDto { }
```

## 9. Enum — перечисления

Enum имеют суффикс `Enum`

```php
enum CancelReasonEnum { }
```

## 10. Factory — фабрики

Фабрики имеют префикс того класса, который они создают и суффикс `Factory`.

```php
// фабрика, которая создает объект передачи данных для сущности City
final class CityResultDtoFactory { }
```

## 11. Command — консольные команды

Команда в префиксе содержит суть для чего она нужна и имеет суффикс `Command`.

```php
final class NotifyWalkingsForPaymentAdminCommand extends Command { }
```

## 12. Normalizer — нормализеры/сериализеры

Нормализер имеет в префиксе сущность, либо отражает суть того, что он нормализует, суффикс `Normalizer`.

```php
// нормализер, который нормализует объект в массив
final class ObjectToArrayNormalizer { }
```

## 13. Trait — трейты

Трейты имеют суффикс `Trait`.

## 14. Helper — хэлперы

В общем случае хэлперы имеют префикс показывающий для работы с чем используются методы, в нем содержащиеся. Суффикс `Helper`.

```php
// класс, в котором содержатся методы для работы со строками
final class StringsHelper { }
```

## 15. Subscriber — подписчики

Подписчик имеет суффикс `Subscriber`.

```php
final class ApiExceptionSubscriber { }
```

## 16. Listener — слушатель

Слушатель имеет суффикс `Listener`.

```php
final class ParamConverterListener implements EventSubscriberInterface { }
```

## 17. UseCase

В названии отражает действие глагол + существительное. Имеет суффикс UseCase.

```php
final class CreateUserUseCase { }

final class GetReviewListUseCase { }
```

Список не является исчерпывающим. Также используются суффиксы Generator, Provider и пр.
