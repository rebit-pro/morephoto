# Работа с массивами

## Описание массивов в phpDoc

Все массивы, если они:
- возвращаются методом
- являются параметром метода
- являются константой класса

**ОБЯЗАТЕЛЬНО** должны быть описаны в phpDoc для PHPStan.

Так мы:
- знаем, что у нас в массиве
- получаем максимум подсказок от phpStorm
- получаем валидацию от PHPStan

### Правила описания

1. Используем **shape-типы phpStan** для сложных структур
2. Переносим на новую строку, если структура сложная
3. Указываем все возможные ключи и их типы
4. Запятая при переносе на всех строках

### Примеры правильного описания

#### Простой массив скаляров

```php
/** @var string[] */
private array $emails;

/** @param int[] $ids */
public function getUsers(array $ids): void { }
```

#### Массив объектов

```php
/**
 * @var array<int, User> // если ключ имеет смысл, то описываем. Например: ключ - ID пользователя 
 */
private array $users;

/**
 * @return array<int, Product> // ключ - ID товара
 */
public function getProducts(): array { }
```

#### Массив с фиксированной структурой (shape-тип)

```php
/**
 * @var array<int, array{
 *     id: int,
 *     name: string,
 *     email: string,
 *     active: bool,
 * }>
 */
private array $userData;

/**
 * @return array<string, array{
 *     total: float,
 *     count: int,
 *     items: array<int, Product>,
 * }>
 */
public function getSummary(): array { }
```

#### Ассоциативный массив неизвестной структуры (string-ключи)

```php
/**
 * @var array<string, mixed>
 */
private array $config;

/**
 * @param array<string, int> $settings
 */
public function updateSettings(array $settings): void { }
```

## Передача данных между методами

В целом нужно **максимально избавляться** от передачи массивов между методами.

Передача должна идти через **DTO** с точно обозначенными полями. Это позволит:
- системе падать сразу, как только появится что-то невалидное
- получить типизацию
- получить подсказки IDE

Для конвертирования массива в DTO используем:
- **частные маперы** (если маппинг специфичен для этого класса)
- **helper `ArrayToDtoMapper`** (если маппинг переиспользуется)

## Пример использования ArrayToDtoMapper

```php
<?php

declare(strict_types=1);

namespace Rebit\Wallet\Application\Product;

use Rebit\Share\Shared\Helper\ArrayToDtoMapper;
use Rebit\Wallet\Application\Product\Dto\ProductItemDto;

final readonly class ProductService
{
    /**
     * @param array<int, array{
     *     id: int,
     *     name: string,
     *     price: float,
     * }> $items
     * @return ProductItemDto[]
     */
    public function mapProducts(array $items): array
    {
        return ArrayToDtoMapper::mapList($items, ProductItemDto::class);
    }
}
```

## Частный маппер

```php
<?php

declare(strict_types=1);

namespace Rebit\Wallet\Application\Product;

use Rebit\Wallet\Application\Product\Dto\ProductItemDto;

final readonly class ProductDtoMapper
{
    /**
     * @param array{
     *     id: int,
     *     name: string,
     *     price: float,
     * } $data
     */
    public function mapToDto(array $data): ProductItemDto
    {
        return new ProductItemDto(
            id: (int)$data['id'],
            name: (string)$data['name'],
            price: (float)$data['price'],
        );
    }

    /**
     * @param array<int, array{
     *     id: int,
     *     name: string,
     *     price: float,
     * }> $items
     *
     * @return array<int, ProductItemDto>
     */
    public function mapCollection(array $items): array
    {
        return array_map(
            fn(array $item): ProductItemDto => $this->mapToDto($item),
            $items,
        );
    }
}
```
