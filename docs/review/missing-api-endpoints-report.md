# Отчёт: Недостающие API-эндпоинты

Дата: 2026-03-26  
Обновлено: 2026-03-26

## Контекст
На основании анализа сценариев (`docs/scenario.md`) и текущей Postman-коллекции
(`docs/review/rebit-wallet-exchange-postman.json`) выявлены эндпоинты, которых не хватало
для полной реализации пользовательских сценариев.

---

## 1. ✅ `PATCH /api/v1/exchange/advertisements/:id` — Запуск/Остановка объявления

**Статус: РЕАЛИЗОВАНО**

- `ToggleAdvertisementRequestDto` — валидация `status` ∈ `['active', 'paused']`
- `ToggleAdvertisementUseCase` — проверка владения, валидация перехода, Bybit cancel/create
- Роут добавлен в `rebit.exchange/routes.php`
- DI подключен в `di/advertisement.php`
- Фронтенд: кнопки ▶/⏸ на странице объявлений

---

## 2. `GET /api/v1/exchange/advertisements/:id` — Детали одного объявления

**Сценарий:** 6, 12.3 (привязка скрипта к объявлению).

**Проблема:** Для редактирования объявления нужен отдельный endpoint.
Сейчас можно получить только список.

**Приоритет:** 🟡 Средний — нужен при реализации экрана редактирования.

---

## 3. `PATCH /api/v1/exchange/advertisements/:id` — Редактирование полей объявления

**Сценарий:** 6, 12.3 (изменение chatScriptId у объявления).

**Проблема:** Невозможно отредактировать параметры объявления (цену, лимиты,
привязку скрипта) без удаления и пересоздания.

**Приоритет:** 🟡 Средний — пока пользователь решил обходиться «пока нет».

---

## 4. Deep link генератор для инициации сделки из стакана

**Сценарий:** 3 (Покупка по предложению из стакана).

**Статус:** 🟢 Низкий — пользователь перенаправляется на Bybit через кнопку.

---

## 5. Кросс-модульный справочник валют

**Статус:** 🟢 Решено — `CurrencyQueryInterface` расширен методом `findCodeById`.
Фронтенд использует `GET /api/v1/exchange/currencies` кросс-модульно.

---

## 6. ✅ `GET /api/v1/wallet/reports/cash-flow` — Отчёт оборотов денежных средств

**Статус: РЕАЛИЗОВАНО**

- `CashFlowFilterRequestDto` — фильтры dateFrom, dateTo, currencyId
- `GetCashFlowReportUseCase` — агрегация по валютам: opening, incoming, outgoing, closing
- `ReportController` в `rebit.wallet`
- Роут: `GET /api/v1/wallet/reports/cash-flow`
- DI: `di/report.php` подключён в `.settings.php`
- Фронтенд: полноценная страница с фильтрами и таблицей
